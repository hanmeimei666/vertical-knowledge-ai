# 青少年体能训练核心课程 · 48课时教研初稿

版本：V0.1；待专业审核。

对象：成年体育教师、体能教练及相关从业者。训练服务对象为青少年。

48课时 × 45分钟＝2160分钟＝36小时；24次课，每次2课时。理论18课时，实践/案例30课时。

这是独立核心课程，不自动获得原150/200学时等级完成或资格认定。足球专项、运动康复与高级竞技周期后置。

课程时间是成年学习者的培训时间，不是青少年单次训练时长。每次90分钟是有效教学时间，中途休息另排；实践课含讲解、观察和反馈，不是90分钟连续运动。

教学顺序、练习、时长分配、作业和评分属于本次教研设计；知识原则通过知识卡回查。不将完整教案称为已验证的国际标准方案。

## 逐次课教案

### L01 · 青少年体能培养什么

模块M1；2课时：理论1、实践/案例1。

**学习目标**：

- 区分健康活动建议、体能训练与教练培训课时
- 写出兼顾能力、信心和持续参与的目标

**核心讲解**：

1. 先从儿童长期参与出发，解释为什么体能目标不能只有短期排名。身体素养的身体、心理、社会和认知维度为目标设计提供观察角度。
2. 用一周活动图解释WHO活动总量：体育课、通学、游戏和训练共同构成活动情境，日均建议不能直接改成每日高强度训练课。
3. 把‘孩子不够努力’改成可观察、可调整的问题：任务是否适合、是否有选择、参与体验如何。多样体验不等于没有训练结构。

**90分钟教学流程建议**：5分钟目标与状态确认 → 20分钟概念讲解 → 20分钟案例判断 → 35分钟任务演练 → 10分钟反馈与评价（45理论+45实践）。

**演练任务**：四人一组为虚拟学校小组画活动周历，提出两个能力目标与一个参与目标，交换检查是否把培训课时当成儿童训练时长。

**提交物**：一页培养目标与活动周历

**教师观察与验收**：

- 能正确区分三种时间概念
- 目标含可观察行为和复核方式
- 不承诺短期效果或用体型排名

**课后巩固**：采访式模拟：写出向家长解释长期发展的150字说明。（不额外计入48课时）。

**原任务映射**：D1（映射表示采用相关内容，不代表完成原任务全部能力）。

**依据与回查**：

- K01 从短期成绩转向长期发展：[S03](https://www.nsca.com/about-us/position-statements/youth-training-and-long-term-athletic-development/long-term-athletic-development-position-statement/) · Official summary；LOCAL-PLAN · B42。
- K02 身体素养的四个维度：[S06](https://www.ausport.gov.au/physical_literacy) · The skills you need to be physically literate。
- K07 日常活动建议不等于单课处方：[S01](https://www.ncbi.nlm.nih.gov/books/NBK566046/) · Recommendations: Children and adolescents aged 5–17 years。
- K29 多样运动体验与自主选择：[S02](https://pubmed.ncbi.nlm.nih.gov/26084524/) · Indexed sport-diversification section；[S06](https://www.ausport.gov.au/physical_literacy) · Psychological and physical domains。

### L02 · 同龄不同起点：成长与训练经历

模块M1；2课时：理论1、实践/案例1。

**学习目标**：

- 分别记录日历年龄、训练经历与成长信息
- 识别成长测量的隐私与自愿条件

**核心讲解**：

1. 展示两名同龄但训练经历不同的虚拟学员，说明年龄不是训练等级，身高变化也不能单独证明成熟状态。
2. 介绍成长监控能帮助理解变化，同时呈现其测量和解释限制。2026综述的伦理原则用于改进实施方式，不作为预测个人损伤的工具。
3. 基于目标动作表现、既往活动经历和可用信息选择训练起点；信息不足时保留未知，不靠外观推断发育情况。

**90分钟教学流程建议**：5分钟目标与状态确认 → 20分钟概念讲解 → 20分钟案例判断 → 35分钟任务演练 → 10分钟反馈与评价（45理论+45实践）。

**演练任务**：为三份虚拟档案分别写入组说明，设计一次非侵入测量的告知、自愿参与、私密记录和退出流程。

**提交物**：三份起点判断卡与测量告知草稿

**教师观察与验收**：

- 年龄、成熟度和训练史未混写
- 有测量目的、限制与隐私安排
- 不公开贴早熟晚熟或体型标签

**课后巩固**：标注档案中仍不足以判断训练起点的两项信息。（不额外计入48课时）。

**原任务映射**：F1（映射表示采用相关内容，不代表完成原任务全部能力）。

**依据与回查**：

- K03 年龄、成熟度与训练经历分开记录：[S02](https://pubmed.ncbi.nlm.nih.gov/26084524/) · Indexed growth and maturation sections；LOCAL-STANDARD · B108.R2。
- K04 成长测量兼顾价值与权益：[S12](https://pubmed.ncbi.nlm.nih.gov/42608346/) · Abstract: five implementation principles；LOCAL-STANDARD · B106.R5。
- K01 从短期成绩转向长期发展：[S03](https://www.nsca.com/about-us/position-statements/youth-training-and-long-term-athletic-development/long-term-athletic-development-position-statement/) · Official summary；LOCAL-PLAN · B42。

### L03 · 参与前核查、保护与异常处置

模块M1；2课时：理论1、实践/案例1。

**学习目标**：

- 完成参与前核查清单
- 将一般准备问题与需停止转介的异常分开

**核心讲解**：

1. 从健康问卷、参与同意、训练限制、场地与责任人开始；存在疑问的限制由相应专业人员确认。教练不独立签发医学参与许可。
2. 使用母版列举的异常情境练习停止、保护、通知、记录与按机构应急流程处理；急救技能由具相应能力的教师承担。
3. 保护不仅是保密，还包括尊重、非惩罚性组织、报告渠道和责任清晰。数字记录采用虚拟编号，不能以‘最高权限’代替实际儿童数据的机构程序。

**90分钟教学流程建议**：5分钟目标与状态确认 → 20分钟概念讲解 → 20分钟案例判断 → 35分钟任务演练 → 10分钟反馈与评价（45理论+45实践）。

**演练任务**：角色轮换处理胸痛、无同意材料、被辱骂和普通器材缺失四个情境，记录动作、通知对象及未决信息。

**提交物**：入组核查表与异常处置记录

**教师观察与验收**：

- 关键异常未继续安排训练
- 责任人和报告路径明确
- 不越权诊断且记录保留事实

**课后巩固**：按所在机构条件补一份应急联系人空表，不填真实儿童信息。（不额外计入48课时）。

**原任务映射**：A1、A3（映射表示采用相关内容，不代表完成原任务全部能力）。

**依据与回查**：

- K05 健康核查与停止转介：LOCAL-STANDARD · B106.R2；LOCAL-PLAN · B39。
- K06 保护参与者是组织责任：[S11](https://bjsm.bmj.com/content/early/2024/11/25/bjsports-2024-108766) · Indexed prevention and response scope；LOCAL-PLAN · B46。
- K11 测评记录与隐私分离：LOCAL-STANDARD · B106.R4。

### L04 · 为训练决策选择最小测试组合

模块M2；2课时：理论1、实践/案例1。

**学习目标**：

- 让每项测试对应可改变的教学决定
- 说明动作观察与损伤预测的区别

**核心讲解**：

1. 先问测试后准备采取什么行动，再选指标；为了增加数据而增加测试，会提高时间负担而不一定改善判断。
2. 动作观察记录任务完成方式和症状，为教学起点提供信息；不能把一个低分写成损伤诊断或必然风险。
3. 区分测试目的、效度、可靠性与可操作性。没有适合人群的协议时保留待核，不自建带官方含义的常模。

**90分钟教学流程建议**：5分钟目标与状态确认 → 20分钟概念讲解 → 20分钟案例判断 → 35分钟任务演练 → 10分钟反馈与评价（45理论+45实践）。

**演练任务**：从十个候选指标中为一组初学者选择不超过四项，逐项写出‘结果A做什么，结果B做什么’并删除无决策价值项目。

**提交物**：最小测评方案与决策对应表

**教师观察与验收**：

- 每项指标有目的和后续行动
- 描述测试人群与协议缺口
- 没有个体伤病概率或淘汰标签

**课后巩固**：为一个常见动作评分写出能用与不能用的两条边界。（不额外计入48课时）。

**原任务映射**：B2、G1（映射表示采用相关内容，不代表完成原任务全部能力）。

**依据与回查**：

- K08 测试从决策问题出发：LOCAL-STANDARD · B108.R5。
- K10 动作观察不是损伤预测诊断：[S09](https://pubmed.ncbi.nlm.nih.gov/27095747/) · Indexed abstract: association versus prediction；LOCAL-STANDARD · B106.R6。
- K30 证据强度与课程设计分开：[S10](https://pubmed.ncbi.nlm.nih.gov/22109781/) · Abstract；[S03](https://www.nsca.com/about-us/position-statements/youth-training-and-long-term-athletic-development/long-term-athletic-development-position-statement/) · Official summary。

### L05 · 测量协议、环境和记录质控

模块M2；2课时：理论1、实践/案例1。

**学习目标**：

- 编写可供另一教师复现的测试协议
- 保留原值并修正记录错误

**核心讲解**：

1. 统一场地、器材、口令、单位、顺序和无效尝试标准。操作前确认器材与安全区，不能把可选设备当成已具备。
2. 身高等测量在受训人员指导和适当隐私下开展；课堂先用成年同伴或模拟数据，测量结果不公开排名。
3. 建立缺失、无效和异常三个不同标记。记录修改保留原值和原因；不把缺测填成零分，也不让AI补造测量值。

**90分钟教学流程建议**：5分钟目标与状态确认 → 20分钟概念讲解 → 20分钟案例判断 → 35分钟任务演练 → 10分钟反馈与评价（45理论+45实践）。

**演练任务**：两组互换协议复现同一低风险测试；检查带有单位混乱、重复编号和缺测的虚拟数据表，并留存修订轨迹。

**提交物**：测试协议v1与质控修改表

**教师观察与验收**：

- 另一组能够按协议执行
- 单位、缺失与无效值可区分
- 修改轨迹与隐私安排完整

**课后巩固**：记录协议交换中产生的两个分歧并给出修订方案。（不额外计入48课时）。

**原任务映射**：A2、A3、B1、G2（映射表示采用相关内容，不代表完成原任务全部能力）。

**依据与回查**：

- K09 标准化与测量误差：LOCAL-STANDARD · B106.R3；LOCAL-STANDARD · B108.R6。
- K11 测评记录与隐私分离：LOCAL-STANDARD · B106.R4。
- K31 轮站、器材与教练一致性：LOCAL-PLAN · B267；LOCAL-PLAN · B270。

### L06 · 基础运动、速度与耐力测评轮站

模块M2；2课时：理论1、实践/案例1。

**学习目标**：

- 在统一协议下完成低风险示范测评
- 解释成绩的限制与复测条件

**核心讲解**：

1. 区分动作观察、短距移动、跳跃和耐力任务的目的，选择已被教师核验的低风险协议；不临时拼接成新标准测试。
2. 先熟悉、示范、练习再记录；观察顺序、疲劳和学习效应如何影响数据。课堂记录标注为成年同伴演练或模拟。
3. 解释结果需结合训练经历、当天状态与误差。一次成绩只回答有限问题，不能证明完整体能水平或长期训练效果。

**90分钟教学流程建议**：5分钟目标与状态确认 → 20分钟概念讲解 → 20分钟案例判断 → 35分钟任务演练 → 10分钟反馈与评价（45理论+45实践）。

**演练任务**：按站点分为执行、保护、记录和观察角色，完成两项示范；教师检查后输出一次数据质量结论。

**提交物**：轮站原始记录与结果限制说明

**教师观察与验收**：

- 有效与无效尝试有依据
- 遵守站点停止条件
- 结果没有超出数据支持范围

**课后巩固**：选择两项未来复测指标，说明如何保持条件一致。（不额外计入48课时）。

**原任务映射**：B2、B3（映射表示采用相关内容，不代表完成原任务全部能力）。

**依据与回查**：

- K08 测试从决策问题出发：LOCAL-STANDARD · B108.R5。
- K09 标准化与测量误差：LOCAL-STANDARD · B106.R3；LOCAL-STANDARD · B108.R6。
- K10 动作观察不是损伤预测诊断：[S09](https://pubmed.ncbi.nlm.nih.gov/27095747/) · Indexed abstract: association versus prediction；LOCAL-STANDARD · B106.R6。
- K27 复测解释承认误差：LOCAL-STANDARD · B106.R15；LOCAL-STANDARD · B108.R7。

### L07 · 从主任务倒推动态热身

模块M3；2课时：理论1、实践/案例1。

**学习目标**：

- 设计与主任务关联的动态热身
- 解释每个环节的作用

**核心讲解**：

1. 依据母版组织体温提升、活动、激活和目标动作低强度预演；5–10分钟为母版起点，不是普适强制时长。
2. 把热身与当天的移动、蹲起或投掷任务连接起来；不以长时间静态拉伸替代全部准备。
3. 游戏化需要目标和观察点。让学员表达状态并选择适合难度，教师根据场地、天气及动作表现调整。

**90分钟教学流程建议**：5分钟目标与状态确认 → 20分钟概念讲解 → 20分钟案例判断 → 35分钟任务演练 → 10分钟反馈与评价（45理论+45实践）。

**演练任务**：两组分别设计移动课与力量课热身，互换带练，逐项指出与主任务的关系以及可用替代。

**提交物**：两套热身任务单

**教师观察与验收**：

- 包含低强度目标动作预演
- 每项安排有理由
- 能根据状态提出适当调整

**课后巩固**：把一项排队等待多的热身改成更有参与机会的组织方式。（不额外计入48课时）。

**原任务映射**：C1（映射表示采用相关内容，不代表完成原任务全部能力）。

**依据与回查**：

- K12 动态热身与动作准备：LOCAL-STANDARD · B106.R8。
- K02 身体素养的四个维度：[S06](https://www.ausport.gov.au/physical_literacy) · The skills you need to be physically literate。

### L08 · 动作观察与清楚的教学反馈

模块M3；2课时：理论0、实践/案例2。

**学习目标**：

- 用可观察语言描述动作
- 根据反馈调整任务而非给人贴标签

**核心讲解**：

1. 观察任务是什么、完成了什么、在哪种条件出现困难。把可观察事实与对原因的推断分开。
2. 教师示范一项简单动作，学员一次给出一条清楚口令，再观察是否帮助完成；避免同时堆叠大量纠错术语。
3. 变式服务于学习目标，改变支点、幅度或环境时说明理由。疼痛等异常先依安全流程处理，不继续用纠错尝试消除。

**90分钟教学流程建议**：10分钟准备与安全确认 → 15分钟教师示范 → 40分钟分组演练 → 15分钟同伴/教师复核 → 10分钟复盘（90实践）。

**演练任务**：三人轮换教练、练习者和记录员，用箱式坐起或平衡任务进行‘观察—一句反馈—再观察’演练。

**提交物**：动作观察与反馈对照表

**教师观察与验收**：

- 事实与推断分栏
- 反馈具体且尊重练习者
- 能提出降阶并说明条件

**课后巩固**：为同一观察写出两个不含诊断的反馈版本。（不额外计入48课时）。

**原任务映射**：B2、C2（映射表示采用相关内容，不代表完成原任务全部能力）。

**依据与回查**：

- K10 动作观察不是损伤预测诊断：[S09](https://pubmed.ncbi.nlm.nih.gov/27095747/) · Indexed abstract: association versus prediction；LOCAL-STANDARD · B106.R6。
- K15 蹲与髋铰链的教学观察：LOCAL-STANDARD · B106.R9。
- K28 报告与家校沟通：LOCAL-STANDARD · B106.R16；[S06](https://www.ausport.gov.au/physical_literacy) · Coaches and providers。

### L09 · 平衡、移动与综合练习轮站

模块M3；2课时：理论0、实践/案例2。

**学习目标**：

- 组织不同能力可参与的综合练习
- 区分研究启发与自行设计活动

**核心讲解**：

1. 介绍综合神经肌肉训练试验的对象、周期和局限，只将其作为嵌入体育课的研究示例。
2. 组合平衡、蹲起、移动与轻物投接，设置可选择难度；活动设计需说明目标，不能称为复制研究方案。
