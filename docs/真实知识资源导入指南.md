# 真实知识资源导入指南

版本：2026-11-15。入口：scripts/import_resources.py。适用于后续每份新资料，不依赖现有青少年体能母版。

## 1. 格式与环境

Python 3.11+、标准库、本地目录可写即可；默认不安装模型、不联网、不需要密钥。

|输入|支持|坐标|
|---|---|---|
|原生DOCX段落/表格|是，原件≤50MB，document.xml≤20MB|Bn/Bn.Rn，不声称页码|
|UTF-8 TXT/MD|是|Ln，保留原行号|
|PDF/扫描图片/音频/视频|当前未启用|须另做解析器与定位验证|

先执行`python scripts/smoke_import.py`。它使用仓库原创演示，在新的本地目录中验证闭环，不需要私有DOCX。

## 2. 原件与准入清单

在项目根目录执行，替换示例中的真实路径：

```powershell
New-Item -ItemType Directory -Force data/raw/incoming
Copy-Item -LiteralPath 'D:\你的资料目录\真实资料.docx' -Destination data/raw/incoming
Copy-Item config/import_manifest.example.json data/my-source.json
```

编辑data/my-source.json：

```json
{
  "id": "YOUTH-RESOURCE-001",
  "title": "实际资源标题",
  "path": "data/raw/incoming/真实资料.docx",
  "provenance": "实际提供方、取得日期、许可依据与用途说明",
  "sensitive": "none",
  "rights": {
    "internal_parse": true,
    "retrieve": true,
    "adapt": true,
    "redistribute": false,
    "model_training": false,
    "external_model_processing": false
  }
}
```

**示例true必须有实际依据，不是对所有新资料的授权。**未知填null；敏感性不明填unknown，个人/儿童健康信息用personal/minor_health，目前统一隔离；确认没有这些信息才填none。

同一资料用稳定id，不同资料不要复用。可填sha256作为预期指纹；不一致停止。标题、来源依据占位语必须替换；解析、检索、改编、分发、训练、云处理分别确认。

## 3. 准备候选批次

```powershell
python scripts/import_resources.py prepare --manifest data/my-source.json --batch youth-resource-001
```

curation_pending表示已生成候选；quarantined表示权限/敏感性不清或原件缺失、不生成正文；rejected表示不允许解析；ERROR表示格式/损坏/路径/指纹等不符。

本地目录data/imports/youth-resource-001包含：

|文件|作用|
|---|---|
|manifest.json|本次登记输入快照，不是自动许可|
|batch.json|源ID、修订、指纹和运行配置快照|
|candidates.json|候选，include/confirmed默认false|
|prepare_report.json|原文块数、候选数、遗漏数|
|commit_intents.json|提交时按key保存校订意图指纹|
|commit_report.json|最后提交结果；任务历史仍在SQLite|

默认前100个原生块生成候选，omitted_blocks如实报告省略数；可在新批次加`--limit 1000`，范围1–1000。完整解析块保留在来源本地记录；大资料可拆章节原件，不能声称前100块就是完整知识原子化。批次名唯一，不覆盖已有候选。

## 4. 校订知识候选

打开candidates.json，选择适用项：

- include=true表示本次纳入；confirmed=true表示操作者已完成本地校订，**不是专业批准**。
- title/tags改为可检索的主题；teaching_application填写真实教学用法，不能留占位语。
- limits保留适用条件、风险、未知项和非个体处方边界。
- origin=source_excerpt时，summary必须逐字匹配源坐标的解析块；改写后不能仍标为原文。
- origin=curator_summary时，summary为编辑归纳，仍需真实对应出处。
- 来源ID、坐标及据此生成的KU-知识ID保持匹配，不能借批次覆盖别的知识。

需多来源归纳时使用[知识单元模板](../config/knowledge_unit.example.json)和`workflow.py add-unit`另行登记；此入口专注单份资料与其候选。

## 5. 确认入库并生产

```powershell
python scripts/import_resources.py commit --batch youth-resource-001 --goal '已选择知识支持的教研主题' --key youth-resource-001-v1
```

先检查所有选中项的确认、字段、原文/坐标、源修订和用途权限，再逐条幂等写入。未确认、占位未填、源撤回/变化、retrieve/adapt未允许均停止。底层磁盘/数据库故障可能中断逐条写入；修复后重试未改变的批次，不宣称整个过程有跨多条/跨文件原子事务。

生产限定knowledge_scope为本批次确认ID，不能拿旧库替代新资料。主题不匹配则no_evidence，不能放宽权限或依赖模型常识强行补全。

返回run_id、状态和成果路径；查看：

```powershell
python scripts/workflow.py inspect <run-id>
python scripts/workflow.py artifact <run-id> lesson.html
```

输出区分原文摘录、编辑归纳和编排建议。真实专家未配置时停在draft_ready；知识校订入库不代表专业正确、教学有效或可公开分发。

## 6. 修订与恢复

|情况|操作|
|---|---|
|同批次同内容同主题重复|同key返回原run|
|校订/主题改变|新key，保留旧记录|
|原件/权限/配置变化|新batch并重新校订，不改旧快照哈希绕过|
|源重新准入，字节相同|修订号变化后旧候选仍拒绝|
|源修订后旧知识|版本绑定不符，退出召回；须显式重新校订入库|
|撤回|`workflow.py withdraw <source-id> --reason '<实际原因>'`，旧受管成果失效|
|生产失败|先inspect；渲染失败resume；模型重试需显式决定|
|同key返回invalidated|输入/实现变化，用新key创建新版本|

日常真实资料走本入口，不加入seed母版。本版升级后，既有编辑知识须显式`workflow.py seed`重新绑定当前源版本；seed会重新纳入编辑知识，请先审阅本地修订。新真实资源保持独立批次管理。

## 7. 随时验证

```powershell
python scripts/smoke_import.py
python -m unittest discover -s tests -v
```

演示覆盖新文件→权限→解析→候选→校订→限定证据→三格式草稿。真实资料仍需真实许可和知识校订；自动抽取、OCR/ASR、云端模型与正式发布不是默认步骤。

data/outputs、清单、候选全文、数据库和备份默认不进Git；examples只放可分享的原创演示。云端前逐源确认external_model_processing并评测实际效果与用量；当前仍为本地规则，不训练模型。
