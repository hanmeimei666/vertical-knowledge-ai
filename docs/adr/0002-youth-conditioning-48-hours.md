# ADR-0002：青少年体能48课时与本地知识卡

日期：2026-11-15。状态：已实现初稿，专业审核待完成。

用户决定优先青少年体能、足球与康复后置，原150/200学时调整到40–60课时。采用48课时、24次课、每课时45分钟，按核心能力重排，不按比例压缩原等级要求。

选项A：结构化JSON知识卡、来源链接和关键词检索，生成可审阅Markdown课程。选项B：先部署向量库、模型生成问答和课程生产服务。

当前采用A：32卡、24课可直接校验与修改，原件在本地留存，来源和教学建议可区分。已通过检索与结构检查，但尚无真实教学对照数据，不能声称A在生成质量上优于B。

代价：不能自由对话、不能语义召回、更新需要教研编辑；来源全文受限仍需补核。迁移触发：资料规模或固定查询集证明关键词不足，或已审核知识足以支撑受控问答。保持来源ID、指纹、定位、知识卡引用、课程课时与审核状态稳定。
