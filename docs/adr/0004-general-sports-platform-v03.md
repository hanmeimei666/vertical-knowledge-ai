# ADR-0004 共享体育知识资产与工具中心
2026-11-22；当前决策。旧ADR保留为历史。
选择：复用Pipeline records/revisions/runs/audit，在新工作空间增量保存通用对象，新增schema_migrations和tool_invocations。分类以独立维度/词条与方向关系建模，知识可共享；JSON Schema保持存储/调用契约。
替代方案：为每门课程建立独立库（不利共享）；全量重写为图数据库和Agent框架（无当前规模收益且迁移风险高）。本轮均不采用。
来源和知识/教学产品/运行数据通过对象kind隔离，个人健康运行数据本轮拒绝。SQLite默认独立共享工作空间；旧主库只备份审计，不就地迁移。迁移复用旧记录表，备份后仅新增表及user_version，回滚到新副本，禁止覆盖。
工具仅代码允许列表，进程超时、输入输出校验、逐用途权限、幂等和执行日志。模型/外部网络不启用；OCR/ASR/视频工具只占位，不能冒称解析能力。
代价：单机单写者、精确标签/关键词，无自动专业适用性判断。未来需要真实模型、独立评测或多用户规模时再更换检索/Worker，契约及血缘保持稳定。
验证：见docs/v03/验收报告.md。
