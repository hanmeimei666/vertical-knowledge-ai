# ADR-0001：以一份资料验证课程草稿

日期：2026-11-14。状态：当前准备路线；实际解析及模型选型待样本验证。

问题：启动包覆盖大量能力，但当前只确定体育教育的一份资料到带来源课程草稿。

候选 A：本地文件 + JSON；优先提取原生文本，确定性来源映射，规则/人工编排基线。
候选 B：数据库 + 检索 + 外部模型编排；随后按效果考虑向量、异步任务等。

当前选择 A 作为起点。理由：样本、预算和出域许可未知，先验证最短链路，不提前配置与该任务无关的服务。

真实比较结果：尚无业务样本结果；本记录不声称 A 已证明优于 B。
成本：本轮无模型调用，无新付费服务；开发时间未计价。
缺点：手工基线自动化程度低，不覆盖多资料语义检索和视频生产。
替换触发：资料增多导致检索不足、需多人并发、或模型在锁定样本上取得可量化净收益且许可允许。
稳定边界：来源指纹、段落/表格坐标、用途记录、证据引用、草稿与审核状态。
