# 工具注册、解析路由与执行
ToolDefinition有版本、状态、类别、能力、adapter_key、输入输出Schema、依赖、运行类型、权限、敏感性、网络/外部处理、确定性、副作用、超时、幂等、审核、健康和配置契约。工具定义由代码注册，adapter_key只能选择显式允许函数；模型字符串不能import模块、执行Python或Shell。

同tool_id仅允许完整定义相同的幂等注册；配置不同明确抛错，不覆盖旧定义。注册输入、health/discover和definitions查询均做深副本，外部不能借嵌套对象改动已注册权限或Schema。register_exporter可重复调用。

## 第二轮审查后的统一授权
执行入口为Platform.extract→ToolRegistry.invoke、produce→export.draft，以及代码直接调用invoke。三者均在启动进程和返回幂等缓存前，通过Platform绑定的授权器查询本地记录；未绑定授权器的Registry默认拒绝。调用者rights只是额外约束，source_ids只是记录选择器，都不签发权限或合成证明。未知data_sensitivity拒绝，当前只执行synthetic_only。

Platform.create_fixture(suffix,id)只生成代码内固定的9格式非专业样本，不接收内容、现有路径或敏感性标志；新目录内文件写成后，将generator/path/sha256作为fixture_origin及asset记录写入现有修订/审计机制。首次抽取补入segments并产生新修订，后续相同内容与调用键保持幂等。无需新增SQL表。旧的自声明synthetic清单没有生成记录时拒绝，须重新运行smoke生成；禁止给真实文件补证明。

授权检查来源admitted状态、sensitive=none、固定生成记录、文件哈希、当前版本及逐项权限。internal_parse、retrieve、adapt、ocr、asr、video_processing、external_processing、external_model_processing和model_training独立检查，不相互推导。固定样本仅前三项为true，其余为false；未知权限不授权，网络/外部处理仍全局禁用。

native_parse绑定项目根/原件目录/文件路径/来源及预期抽取修订；export_draft必须与数据库中的完整Run快照相同，逐一重验所有来源、retrieve/adapt权限和引用版本；echo仅能处理生成JSON来源的准确内容，不能借无害测试适配器传入任意资料。未实现来源绑定的新适配器拒绝执行。共享检索使用同一来源授权，排除无生成证明、已撤回或权限不足的来源。

信任边界：本地应用代码、固定生成器、SQLite写者和人工整理者属于可信控制面；CLI清单、Request、工具payload、rights及模型输出不属于该控制面。直接改代码/数据库或调用旧parse_file/Pipeline底层函数属于本地受信开发操作，现有单进程工具门禁不宣称是隔离任意Python代码的沙箱。历史旧流程保留，但不会签发fixture_origin，不可借其来源记录调用synthetic_only工具。本轮不开放真实资料导入。

发现/能力过滤→依赖及适配器健康→用途权限→输入Schema→本地spawn进程→超时终止→输出Schema→ToolResult。ToolInvocation持久记录请求指纹、工具版本、结果/错误/时间；同key同请求返回原结果，异请求拒绝；中断状态需明确新尝试。网络/外部处理本轮总开关拒绝，OCR/ASR不会从internal_parse推导授权。

implemented/available/unavailable_dependency/disabled_by_policy/planned/failed_health_check为定义/探测状态。当前health仅检查依赖可导入、适配器允许，不替代真实业务测试。工具超时进程会终止，不再继续背景执行。日志在本地库可能含测试输出，不公开数据库。

ParserRegistry后缀路由调用同一标准输出。可用：原生文本/HTML/CSV/JSON/OOXML、可选pypdf/Pillow、WAV元数据。无依赖则unavailable_dependency。ocr/asr/ffmpeg/semantic/mcp当前planned，有明确占位接口且不可调用；无OCR/ASR/视频处理实现。本轮没有下载权重。未来适配需显式注册函数、依赖、细分权限、定位输出与质量验证。

Exporter保留MD/HTML/JSON，沿用旧renderer，输出独立Artifact契约。ProductionRun在旧runs记录证据、蓝图和导出检查点；失败显式platform_cli resume；不自动调用模型或批准。真实Ollama/OpenAI保留旧适配器，通用模型分类/抽取/关系/翻译等暂只有任务与工具扩展契约，未验证模型效果。
