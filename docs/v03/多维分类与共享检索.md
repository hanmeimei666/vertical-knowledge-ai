# 多维分类与共享检索
六个配置维度：population/domain/scenario/goal/media/applicability。词条有独立id、version、status和parents；父子同维且禁止环。可新增任意维度、词条，不改表。跨维用有方向KnowledgeRelation连接；关系类型可用RelationType记录扩展，候选关系不能直接approved。

KnowledgeUnit除命题/解释外，Schema含概念、多维关联、population/domain/scenario/activity scope、先修、applicability、contraindications/safety、证据/媒体、审核、有效期和版本/时间。必填为独立命题、类型、适用性说明、多维关联、证据及待审/证据等级；其余按资料可选，未知不填成事实。

检索实现精确词面包含+多维过滤：维度内选项OR，维度间可AND/OR；跨领域共享同一知识ID/同一来源，不复制专业分库。标签并不证明专业适用性，EvidencePack保留提示。当前标签筛选精确匹配，不自动展开子树；无自动同义消歧/冲突裁定。

每个引用绑定source_asset_id、source_revision、segment_id及locator；知识校订必须显式confirm。检索逐引用核查admitted、当前修订、retrieve及目的权利，任一不符整条过滤。源更新导致旧知识失配；旧任务以综合指纹失效。

Retriever/KeywordRetriever是替换边界；向量、混合、重排/MCP均planned，不安装索引。旧关键词基线保持原流程。正式源记录永远不是向量投影，后者未来须能重建。模拟alpha/beta两个领域可检索同一条SYN-K，证明结构共享，不是体育领域真实有效性评测。
