# 架构参考依据与采用边界
核查日期2026-11-22；只研究架构，不导入体育专业知识。以下是设计借鉴，不声明完整标准兼容/认证。

|资料|用于本项目哪项决策|实际采用边界|
|---|---|---|
|[EXMO 2024](https://doi.org/10.1038/s41597-024-04217-9)|运动概念及对象关系的未来术语对齐|原站身份重定向不可访问，全文未核查；只保留候选依据，不声称实施其词典|
|[COPPER 2025](https://doi.org/10.1186/s12966-025-01744-5)|人群/环境/活动条件分离的多维设计|已访问文章页面；不导入其知识，不把本项目标签视为专业推荐算法|
|[PROV-O](https://www.w3.org/TR/prov-o/)|来源实体、处理活动、操作者及派生链|SourceRevision/ExtractionRun/Invocation/Artifact映射；未实现RDF序列化|
|[ODRL](https://www.w3.org/TR/odrl-model/)|逐行为权利而非资料可读即全授权|六用途+OCR/ASR等细分权限；不声称完整ODRL策略引擎|
|[Web Annotation](https://www.w3.org/TR/annotation-model/)|目标资源+精确selector|多类型locator/源版本绑定；缺bbox明确缺失，非完整互操作实现|
|[1EdTech CASE](https://www.1edtech.org/standards/case)|Competency与学习目标独立于课程|Schema槽位，未导入能力标准或实现CASE服务|
|[Open edX Content Libraries](https://docs.openedx.org/en/latest/educators/concepts/instructional_design/content_libraries.html)|知识资产/可复用教学单元独立于产品|LearningUnit/Blueprint分离，未接edX|
|[H5P](https://h5p.org/documentation/for-authors/import-and-export)|交互内容独立打包、复用|Exporter预留，不生成H5P包|
|[MCP](https://modelcontextprotocol.io/)|发现/Schema/调用结果的工具边界|本地ToolRegistry；无MCP服务端或外部网关|
|[xAPI](https://github.com/adlnet/xAPI-Spec)|学习事件与知识库分离|未来事件接口，不记录真实学习数据|
|[FHIR Observation](https://hl7.org/fhir/observation.html)|测量值/单位/观察背景需独立对象|未来结构映射，不建设医疗系统或导入健康数据|
|[Docling](https://github.com/docling-project/docling) / [Unstructured](https://github.com/Unstructured-IO/unstructured)|多解析器输出标准化|本轮用轻量本地解析，不安装这两个框架；复杂版式适配候选|
|[Whisper](https://github.com/openai/whisper)|ASR时间段/模型依赖与语义推断分离|接口planned，未安装或下载模型|
|[FFmpeg](https://ffmpeg.org/documentation.html)|音轨/帧/片段原时间基独立|接口planned，缺工具，不假造处理成果|

研究只支持工程对象与接口取舍，不证明运动训练/康复结论，不替代专家审阅。
