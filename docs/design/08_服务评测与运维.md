# B08 本机服务、评测、备份与扩展

## 本机只读API

服务仅绑定127.0.0.1；启动需要至少24字符的环境token。token仅在当前PowerShell进程生成，不输出值：

```powershell
$env:VKA_SERVICE_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(32))"
python scripts/serve.py
```

保持服务进程运行；客户端从自己的安全配置取得同一token，通过Authorization: Bearer发送，不将token放URL。浏览器直接访问受保护页因没有请求头会401；可直接打开本地HTML草稿，API面向程序调用。

|方法/路径|认证|返回|
|---|---|---|
|GET /health|无|仅alive，不返回目录/秘密|
|GET /search?q=主题|Bearer|EvidencePack，问题1–2000字符|
|GET /runs/{id}|Bearer|当前任务快照、状态、审核及步骤；失效任务只返回状态概要，不返回历史证据|
|GET /artifact?id={id}&name=lesson.html|Bearer|检查状态/哈希后返回文件|
|GET /artifact?...&release=true|Bearer|仅published的内部版本|
|POST 任意路径|不提供写能力|405|

未知路由404，认证失败401，记录不可用/失效409，配置/数据异常500。响应no-store、nosniff和CSP；无CORS开放、无静态目录遍历、无任意文件下载、无原文全文端点。持有token者可以访问本项目全部允许内容，这是单项目作用域，没有多租户隔离。HTTPS、公网网关、速率限制、多人RBAC和异步Worker均未实现，不能将该服务直接暴露公网。

## 分层验收

|层|命令/证据|保证与不保证|
|---|---|---|
|准备|check_readiness.py|文件/配置基础可用；不是业务通过|
|业务结构|knowledge.py verify|48课时、卡/来源、合法坐标、可用原件指纹；不是专业签审|
|运行流程|tests/test_pipeline.py|权限、原件/产物变化、状态机、审核、撤回、断点、API真实本机HTTP|
|模型适配|ModelContractChecks|本机HTTP替身和OpenAI无网络契约；不是真实模型质量|
|检索|evaluate.py + baseline-1|逐题Hit@3和无证据；小规模开发回归，非盲测|
|专业/业务|人工签审、真实试教|目前待进行，不把自动通过当成教学有效|

```powershell
python scripts/check_readiness.py
python scripts/knowledge.py verify
python -m unittest discover -s tests -v
python scripts/evaluate.py
```

自动验收要求：所有单元/集成测试通过；知识结构无错误；版本化12题集中Hit@3≥0.8且2条无证据全部正确；失败题逐项保留。此阈值仅为原型开发门槛，不是行业专业合格标准。

评测输出每次写入outputs/evaluation的新UUID文件，不覆盖旧报告，含UTC时间、题集/输入指纹和失败样本。模型费用本轮为0次调用；开发时间和已有设备费用未计价。

## 备份和恢复

`python scripts/workflow.py backup`通过SQLite Backup API生成outputs/backups/<uuid>.sqlite3并做integrity_check。它只备份数据库，不能替代原件、outputs成果、配置及知识输入的受控备份；备份包含解析和任务内部数据，不能提交Git。

恢复操作：停止所有写命令和服务→在**新目录**复制经许可的原件、成果、配置与代码→将备份SQLite放到新配置指定路径→校验源/成果指纹及SQLite完整性→用status、inspect、artifact复核→再允许生产。当前没有一键覆盖恢复或自动删除脚本，避免覆盖现有运行库。代码/配置不一致可能按设计失效旧任务，不能通过手改input_hash绕过。

本轮验证备份可独立打开且审计记录存在；没有做设备损毁/异地灾备演练。备份保留期、加密和访问权限由负责人在生产化前确定。

## 单机运行限制与升级条件

当前限定一个可信写入操作者串行执行，读API按需使用。SQLite事务保证每次记录/状态写入，但没有跨进程任务租约、分布式锁或多Worker幂等外部调用保障。多人并发、长时媒体处理或需要在线写入时，升级事务库/队列及身份服务，并先通过并发、恢复、授权和费用测试。

|扩展|继续条件|必须保留的契约|
|---|---|---|
|OCR/ASR|合法样本、关键参数准确率与源坐标验证|SourceRevision/ParsedBlock，校订不覆盖机器原文|
|向量/混合检索|独立同义查询评测证明净收益|用途过滤、EvidencePack、无证据|
|真实云端/本地模型|端点/名称/资源可用，真实用量质量评测|ID白名单、外发门禁、prompt版本、失败保护|
|视频|源素材许可、时码映射、专业动作审核、成本|蓝图、产物哈希、可播放验收|
|MCP|确有MCP调用方|复用只读/写入分权，不授予发布默认权限|
|公开多用户产品|责任主体、身份、租户、访问/留存/版权规则落实|来源可核、权限分离、审核与审计|
|第二领域|真实样本完整闭环|引擎尽量不变，领域规则/知识替换；不能只改名称宣称验证|
