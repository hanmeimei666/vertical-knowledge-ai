# B03 知识契约、版本与存储

## 从证据到知识

原文解析→人工选取独立命题→补足适用条件和限制→绑定源ID/坐标→入库review_pending→用于带警示的内部教研草稿。当前不自动把固定字数切片升级为知识，也不自动合并冲突主张。专家审核发生于最终成果，不能反向推定每个知识单元已获永久批准。

知识单元最小输入与原有cards.json一致：

```json
{
  "id": "KNEW",
  "title": "独立命题标题",
  "tags": ["主题"],
  "summary": "编辑归纳，不能假装原书逐字引语",
  "teaching_application": "建议的教学用法",
  "limits": "适用条件、风险和未知项",
  "references": [{"source": "EXAMPLE-001", "locator": "L1"}]
}
```

执行`python scripts/workflow.py add-unit data/my-unit.json`。来源必须存在，定位非空；有原生定位清单时必须在清单内。运行时review_state=review_pending，origin默认curator_summary；也可显式source_excerpt，此时必须逐字匹配一个真实解析块。无来源、空条件字段、非法坐标不入库。资产处于隔离时可保留知识候选，但检索和生产不会使用它。

知识同时保存source_versions，逐源绑定修订号与指纹；源更新后旧知识不再召回，须显式校订入库。后续真实资源用[批次入口](../真实知识资源导入指南.md)，原文块只作候选，确认后才进入知识层。新环境一键验证使用smoke_import.py。

## 五级对象映射

|逻辑层|最小对象|物理实现|
|---|---|---|
|L0|SourceAsset/Revision|raw原件；records(kind=asset)、revisions；指纹及rights|
|L1|ParsedBlock/SourceSpan|资产body.blocks/locators；绑定当前修订，不声称独立审核|
|L2|KnowledgeUnit/EvidenceLink|records(kind=unit)、references；summary/limits/origin|
|L3|ReusableUnit|本期复用teaching_application；已有课次和表单独立保留，不强建媒体实体|
|L4|RequestSpec/EvidencePack/Blueprint/Run/Artifact|runs.request/steps/snapshot；outputs文件及哈希|

## SQLite结构

|表|主要键/字段|职责|
|---|---|---|
|records|kind+id；revision/sha/state/body|当前可用版本；知识与来源统一简表|
|revisions|kind+id+revision；sha/state/body/created|只增修订快照；应用不更新旧修订|
|runs|id；request_key唯一；request_hash/state/input_hash/snapshot/steps/error/review|持久执行与快照|
|audit|seq；created/action/object_id/metadata|操作轨迹，默认不写正文、完整问题或秘密|

SQLite在data下，含本地解析正文，不进入Git。知识目录JSON为可审阅的编辑输入，运行目录SQLite为工作流实际状态；修改JSON后须显式seed/add-unit，不能假设文件自动同步。seed可更新编辑知识卡，因此正式项目中应在变更审阅后运行。查权限以SQLite当前记录为准，原来源目录不是运行时许可表。

## 修订与血缘

记录body和state共同计算sha；相同内容幂等，不同内容revision+1。EvidencePack每条引用保存source_revision/source_hash/original_sha256；知识也保存revision/hash。run.input_hash汇总当前全目录版本、运行配置、领域规则及引擎/模型适配代码指纹。

本期采取保守策略：任一资产/知识变动使已有未阻断任务整体失效，不尝试精细判断“无关更新”。优点是不会静默沿用过期批准；代价是重新生产较多。库规模大后可按已记录的证据引用实现依赖图，只失效下游任务。向量索引若以后加入，须可由上述正式记录重建。

原始证据、编辑归纳、模型/规则教学建议和审核意见在输出中分开；不覆盖源文，不将模型建议写回权威知识。反馈回流需要人工修订知识并新增版本，当前没有自动学习或训练作业。

## 删除和纠错

`withdraw`为逻辑撤回，保留审计和修订，默认不物理删除原件。实际敏感信息删除、备份清除与保留期需负责人另定；当前没有自动删除任务。模型训练权限即使为true，也不触发训练——本项目没有训练实现。
