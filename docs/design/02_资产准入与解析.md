# B02 资产准入与解析

后续真实资料优先使用[批次导入指南](../真实知识资源导入指南.md)；prepare生成候选，commit校订入库并限定本批次证据生产。下文admit仍是底层单资产接口。

## 流程

登记来源身份→六项用途权限→敏感性→文件指纹→准入决定→允许时原生解析→版本入库。取得资料不等于可解析，解析不等于可改编或公开。

`config/import_manifest.example.json`是显式输入。替换其中占位文字、文件路径和真实用途依据后执行：

```powershell
python scripts/workflow.py admit path-to-local-manifest.json
```

manifest可以放在本地data目录，避免授权细节进入Git；原件必须放在配置raw_directory内。

## 准入契约

|字段|要求|
|---|---|
|id|1–80字符字母/数字/下划线/连字符，稳定资料标识|
|title|可识别的来源标题|
|provenance|提供者、取得方式、授权依据；不能为空|
|path|受管原件相对路径；元数据归纳可用representation=curated_summary|
|sha256|可选预期指纹；不一致停止，不自动认成新版本|
|sensitive|none/unknown/personal/minor_health，必须明确填写|
|rights|六项全列出；值只能true/false/null|

六项分别为internal_parse、retrieve、adapt、redistribute、model_training、external_model_processing。null是未知，不能按true使用。

|条件|状态|实际行为|
|---|---|---|
|internal_parse=false|rejected|不解析、不检索、不生成|
|internal_parse未知或sensitive非none|quarantined|仅登记和指纹，不解析正文、不进生产|
|原件缺失|quarantined|保留缺失说明，不能假称解析成功|
|允许解析且无敏感标记|admitted|检查文件与格式并提取；其他用途仍逐项门禁|
|损坏/不支持格式/预期指纹不一致|命令错误|此次导入不完成，不生成假文本|

运行时不做自动敏感信息识别，登记者对分类负责。涉及真实儿童或健康信息目前统一隔离，专项脱敏和权限流程尚未开发。

## 原生解析实现与限制

|输入|实现|证据定位|本轮状态|
|---|---|---|---|
|DOCX原生段落、表格|Zip+ElementTree；最大原件50MB，document.xml 20MB|word/document.xml正文子元素Bn、表格行Rn|已运行两份实际大纲|
|UTF-8 TXT/MD|逐行读取|Ln|权限/流程自动测试已验证|
|PDF原生/扫描、图片|预留parse接口，不自动猜测|拟页码+bbox|设计中，当前报不支持|
|音频|拟ASR独立任务，机器转写与校订分开|轨道+起止毫秒|设计中|
|视频|拟画面/口播/字幕分开解析，再按源时基关联|源轨道+起止毫秒|设计中|

DOCX坐标不声称页码。当前不提取浮动图形/页眉脚注，不处理宏，不执行嵌入对象。扫描型空文本明确报错，不把空解析升级为可信知识。

未来解析器统一接收SourceRevision，输出`{locator,text,method,quality,revision}`候选，不直接授予知识审核状态；低质量关键参数须人工校订后进入B03。OCR/ASR选型须用真实许可样本比较准确率、定位、费用后再启用。

## 现有资产迁移与更新

`seed`把来源目录及32张编辑知识卡纳入真实SQLite；本地两份DOCX重新按指纹和B/R检查，国际来源只登记原创归纳与元数据，不代表持有原论文全文。初始仅允许项目内部解析/检索/改编，外发、训练和再分发不由此推导。

再次seed不会覆盖已有来源的撤回或权限决定，也不会自动恢复缺失原件的隔离。恢复原件或更新权限时，先查看来源记录，再用完整manifest显式admit。不要用模板猜填权限；若提供sha256，更新原件时先核对新指纹并记录原因。

准入不覆盖原文件；同ID有实质变化会新增修订。来源修改、撤回会使旧生产成果失效，见B07。测试覆盖未知权限、敏感隔离、非法坐标、路径越界、解析不支持、源指纹变化。
